How this dev view works
  • Reads the same weekly labour data as the main dashboard.
  • Adds salaried management and remittance % from settings/app.
  • Looks for a FOH/BOH doc at companies/aidan/locations/{location}/fohBoh/{weekISO}.
  • That doc should contain numbers like foh_labor, boh_labor, foh_target_pct, boh_target_pct (targets as decimals, e.g. 0.18).
  • If the FOH/BOH doc is missing, the cards will show dashes and a hint.

Dev-only page. Safe to change without affecting the main Labour Dashboard or its PDF generator.
